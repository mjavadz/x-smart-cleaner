# 🛡️ X Smart Cleaner (پالایشگر هوشمند و ایمن توییتر)

یک اکستنشن متن‌باز، سبک و کاملاً محلی برای مرورگرهای مبتنی بر کرومیوم (Chrome, Brave, Edge) جهت **شناسایی و آنفالوی خودکار اکانت‌هایی که به شما فالوبک نداده‌اند**، با رعایت کامل پروتکل‌های ایمنی، فیلتر هوشمند افراد سرشناس و تاخیر تصادفی رفتار انسانی.

---

## 🌟 چرا این ابزار ساخته شد؟
اکثر وب‌سایت‌ها و اپلیکیشن‌های آنفالویاب موجود:
1. از شما **نام‌کاربری و رمز عبور** می‌خواهند که خطر امنیتی بزرگی برای اکانت است.
2. با ارسال درخواست‌های فله‌ای و بدون تاخیر انسانی در کسری از ثانیه، باعث مسدود شدن (Suspend) یا شادوبن شدن اکانت در الگوریتم‌های توییتر می‌شوند.
3. تفاوتی بین دوستان عادی و رسانه‌ها/افراد معروف که طبیعی است فالوبک ندهند قائل نمی‌شوند.

**X Smart Cleaner** تمام این فرآیند را **۱۰۰٪ در محیط مرورگر خودتان (Client-Side)** و با سشن فعال شما انجام می‌دهد، بدون اینکه هیچ داده‌ای به سروری فرستاده شود.

---

## 🚀 ویژگی‌های کلیدی
- **🔒 امنیت مطلق (Zero-Knowledge):** بدون نیاز به وارد کردن پسورد، ایمیل یا کلید API.
- **🧠 فیلتر هوشمند و لیست سفید (Whitelist):**
  - امکان محافظت خودکار از اکانت‌های بالای ۱۰,۰۰۰ یا ۲۰,۰۰۰ فالور (رسانه‌ها و سلبریتی‌ها).
  - امکان تعریف لیست سفید دلخواه از آیدی‌هایی که مایلید هرگز آنفالو نشوند.
- **⏱ رفتار انسانی ضداسپم (Anti-Spam Human Delay):**
  - فواصل زمانی تصادفی متغیر (۴ تا ۸.۵ ثانیه) بین هر آنفالو برای جلوگیری از هرگونه لیمیت یا کپچا.
  - تقسیم کار به پارت‌های انتخابی (۵۰، ۱۰۰ یا دلخواه).
- **📊 طراحی مدرن بنتو (Bento Grid):**
  - نمایش زنده تعداد کل دنبال‌شوندگان، اکانت‌های متقابل (Mutuals) و موارد قابل آنفالو.
  - نوار پیشرفت زنده و لاگ کنسول داخلی.

## 💻 راهنمای نصب (کمتر از ۱ دقیقه)

1. پوشه این مخزن را دانلود کرده یا کلون کنید:
   ```bash
   git clone https://github.com/mjavadz/x-smart-cleaner.git
   ```
   *(یا فایل ZIP را دانلود و Extract کنید).*

2. مرورگر کروم، بریو یا اج را باز کرده و به آدرس زیر بروید:
   ```text
   chrome://extensions/
   ```

3. از گوشه بالا سمت راست، کلید **Developer mode (حالت توسعه‌دهنده)** را روشن کنید.

4. روی دکمه **Load unpacked (بارگذاری بدون بسته‌بندی)** کلیک کرده و پوشه پروژه را انتخاب کنید.

5. اکستنشن به نوار ابزار مرورگر اضافه می‌شود!

---

## 📖 نحوه استفاده
1. در یک تب به اکانت خود در سایت **[x.com](https://x.com)** یا صفحه فالویینگ‌های خود (`x.com/YOUR_USERNAME/following`) بروید.
2. روی آیکون اکستنشن کلیک کنید (شناسه اکانت شما با نشانگر سبز نمایش داده می‌شود).
3. آستانه فیلتر (مثلاً حفظ بالای ۲۰k فالور) و سقف پارت را انتخاب کنید.
4. روی **«اسکن و تحلیل لیست»** کلیک کنید.
5. پس از مشاهده آمار، دکمه **«شروع آنفالوی ایمن»** را بزنید و روند کار را در لاگ زنده تماشا کنید.
